# Wedding Invitation

Website thiệp cưới trực tuyến được xây dựng bằng HTML, CSS và JavaScript, với giao diện lãng mạn, hiệu ứng chuyển động và nhạc nền, giúp chia sẻ thông tin lễ cưới đến người thân và bạn bè.

## Demo

**Live Demo:** [Xem thiệp cưới](https://xphung06-dev.github.io/wd-invitation/)

## Features

- Giao diện thiệp cưới trực tuyến tương thích với máy tính và điện thoại.
- Cá nhân hóa tên người nhận thông qua URL.
- Nhạc nền và hiệu ứng mở thiệp.
- Hiệu ứng cánh hoa và xuất hiện nội dung khi cuộn trang.
- Tự động cuộn nội dung thiệp.
- Bộ đếm thời gian đến ngày cưới.
- Thư viện ảnh với chế độ xem ảnh phóng to.
- Thêm sự kiện lễ cưới vào Google Calendar.
- Liên kết Google Maps đến địa điểm tổ chức lễ cưới.

## Technologies

## Personalized Invitation

Website hỗ trợ thay đổi tên người nhận trực tiếp trên đường link mà không cần chỉnh sửa mã nguồn.

Ví dụ:
https://xphung06-dev.github.io/wd-invitation/?to=Ban%20Phung

Thay `Phụng` bằng tên người nhận mong muốn.

Nếu tên có khoảng trắng hoặc ký tự đặc biệt, nên mã hóa URL để đường link hoạt động chính xác.

## Deployment

Website được triển khai miễn phí thông qua GitHub Pages.

1. Push source code lên GitHub repository.
2. Truy cập **Settings → Pages**.
3. Chọn **Deploy from a branch**.
4. Chọn nhánh `main` và thư mục `/ (root)`.
5. Lưu cấu hình và truy cập đường link GitHub Pages sau khi triển khai hoàn tất.
